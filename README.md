# MedOS

سیستم اطلاعات بالینی شخصی — برای بیماران، همکاران و دانستنی‌های خودم.

اپلیکیشن اندروید، فارسی و راست‌چین، کاملاً آفلاین. هیچ داده‌ی بیماری روی سرور کسی ذخیره نمی‌شود.

*A personal, offline-first clinical record for one physician: Android, Persian RTL, encrypted backups the owner controls. Not a product and not for other users.*

---

## نصب روی گوشی

فایل نصبی با دستور `npm run apk` ساخته می‌شود (پایین‌تر توضیح داده شده) و در `dist/MedOS-<نسخه>.apk` قرار می‌گیرد. این پوشه عمداً در git نیست.

۱. فایل را به گوشی منتقل کنید (کابل، تلگرام Saved Messages، هر روشی)
۲. روی گوشی بازش کنید. اندروید می‌پرسد «نصب از منبع ناشناس» مجاز است؟ — اجازه بدهید
۳. نصب کنید و باز کنید

برای نسخه‌های بعدی هم همین کار را بکنید: نسخه‌ی جدید **روی** قبلی نصب می‌شود و اطلاعات سر جایش می‌ماند.

---

## ⚠️ دو چیز که باید همین امروز جایی امن نگه دارید

### ۱. پوشه‌ی `private/`

داخلش کلید امضای اپ است (`medos-release.keystore` و `keystore.properties`). اندروید فقط نسخه‌ای را روی اپ نصب‌شده آپدیت می‌کند که با **همین کلید** امضا شده باشد. اگر این پوشه گم شود، برای نصب نسخه‌ی جدید باید اپ را حذف کنید — یعنی **همه‌ی اطلاعات گوشی پاک می‌شود**.

یک کپی از این پوشه را روی فلش یا فضای ابری شخصی بگذارید. این پوشه عمداً در git نیست و هیچ‌وقت نباید باشد.

### ۲. رمز بکاپ

اولین بار که به «بیشتر ← پشتیبان‌گیری» بروید، رمز بکاپ می‌خواهد. بدون این رمز هیچ بکاپی باز نمی‌شود — حتی توسط من. جایی غیر از گوشی بنویسیدش، و گاهی با دکمه‌ی «آزمایش رمز بکاپ» امتحان کنید که هنوز یادتان است.

---

## قبل از وارد کردن اولین بیمار واقعی

۱. **بیشتر ← پشتیبان‌گیری**: رمز بگذارید، یک پوشه انتخاب کنید. بهترین پوشه، پوشه‌ای است که Google Drive یا OneDrive یا Syncthing همگامش می‌کند — آن‌وقت هر بکاپ خودکار یک نسخه بیرون از گوشی هم دارد.
۲. **بیشتر ← تنظیمات ← قفل اپ**: روشنش کنید.
۳. یک بار «بکاپ کامل الان» بزنید و مطمئن شوید فایل در پوشه ساخته شد.

## ساخت نسخه‌ی جدید و تست روی گوشی

یک بار، بعد از دریافت پروژه:

```bash
npm install
```

هیچ تنظیم دیگری لازم نیست؛ جاوا و Android SDK خودکار از داخل Android Studio پیدا می‌شوند.

### ساخت فایل نصبی (APK)

```bash
npm run apk
```

فایل در `dist/` ساخته می‌شود. بار اول حدود ۲۰ دقیقه، دفعات بعد چند دقیقه. اگر وسط کار «Connection timed out» دیدید، ایراد از اتصال اینترنت است نه کد؛ دوباره اجرا کنید.

### اجرا روی گوشی برای تست و توسعه

گوشی را با کابل وصل کنید (Developer options و USB debugging روشن)، بعد:

```bash
npm run android
```

این یک اپ **جدا** به اسم **MedOS Dev** روی گوشی نصب می‌کند و هر تغییری در کد، چند ثانیه بعد روی گوشی دیده می‌شود.

**MedOS و MedOS Dev دو اپ جدا با دو دیتابیس جدا هستند.** اطلاعات واقعی بیماران در MedOS است و هر آزمایشی در MedOS Dev انجام می‌شود، پس تست کردن هیچ‌وقت به اطلاعات واقعی دست نمی‌زند.

### با Android Studio

پوشه‌ی `apps/mobile/android` را در Android Studio باز کنید و منتظر بمانید تا Gradle sync تمام شود. دکمه‌ی Run همان MedOS Dev را نصب می‌کند.

دو نکته:
- قبلش در یک ترمینال `npm run start` را اجرا کنید؛ نسخه‌ی Dev کد برنامه را از کامپیوتر می‌گیرد.
- اگر Android Studio هر وقت پرسید «اپ موجود را حذف کنم؟» (uninstall)، **نه** بزنید و بپرسید چرا. حذف اپ یعنی حذف اطلاعات همان اپ.

### بررسی کامل کد

```bash
npm run check
```

این دستور همه‌ی بررسی‌ها را اجرا می‌کند: تایپ‌ها، قواعد معماری و کدنویسی، قالب‌بندی، و بیش از ۲۷۰ تست خودکار. هر تغییری در کد باید این را بدون خطا رد کند. روی گیت‌هاب هم با هر push همین بررسی‌ها خودکار اجرا می‌شود.

قوانین کار برای هر کسی (آدم یا هوش مصنوعی) در [AGENTS.md](AGENTS.md)، تصمیم‌های معماری در [docs/architecture.md](docs/architecture.md)، و راهنمای ساخت اندروید در [docs/android-build.md](docs/android-build.md) است.

## وقتی چند هوش مصنوعی روی پروژه کار می‌کنند

قاعده‌ی اصلی: **هیچ چیز مهمی داخل پنجره‌ی چت نمی‌ماند.** هر قاعده و هر وضعیتی که نفر بعدی لازم دارد، یک فایل داخل همین مخزن است. فرض بر این است که جلسه‌ی بعدی یک مدل دیگر از یک شرکت دیگر است که هیچ حافظه‌ای از قبل ندارد.

| فایل | کارش |
|---|---|
| `AGENTS.md` | قرارداد کار: تصمیم‌های قفل‌شده، ۱۱ قانون غیرقابل نقض، جای هر کد، و پروتکل شروع و پایان هر جلسه |
| `docs/HANDOFF.md` | دفتر تحویل شیفت: هر جلسه آخر کار می‌نویسد چه کرد، **چه چیزی را واقعاً تست کرد**، چه چیزی تست‌نشده ماند، و چه کاری برای نفر بعد باز است |
| `docs/architecture.md` | چرا هر تصمیم فنی گرفته شد و چه گزینه‌ای رد شد |
| `docs/review-guide.md` | راهنمای ده‌دقیقه‌ای برای دوست برنامه‌نویس شما (انگلیسی) |

`CLAUDE.md`، `.cursor/rules/medos.mdc` و `.github/copilot-instructions.md` فقط اشاره‌گر به `AGENTS.md` هستند تا هر ابزاری (Claude Code، Cursor، Copilot، …) خودکار همان یک قرارداد را بخواند.

**شروع هر جلسه با هر ایجنتی، فقط همین یک جمله:**

> Read `AGENTS.md` and `docs/HANDOFF.md`, then run `npm run brief` and `npm run check`.

`npm run brief` در یک صفحه نشان می‌دهد: نسخه، آخرین کامیت‌ها با نام ایجنتی که انجامش داده، و کارهای بازی که جلسه‌ی قبل نوشته است.

**چیزهایی که به حافظه‌ی هیچ‌کس تکیه ندارند** (ماشین چک می‌کند، نه آدم): `npm run check` قبل از هر push خودکار اجرا می‌شود (git hook)، روی گیت‌هاب هم دوباره اجرا می‌شود، و چند قانون که با چشم دیده نمی‌شوند — مثل «حذف واقعی داده‌ی بالینی» یا «تراکنش async» — به‌صورت قاعده‌ی lint درآمده‌اند و کد را رد می‌کنند.

برای چت‌های وب (که به مخزن دسترسی ندارند) یک متن آماده در بخش ۸ فایل `AGENTS.md` هست؛ همان را اول گفتگو بچسبانید.

## الان چه دارد

**بیماران**
- لیست با جستجوی فارسی (ی/ي و ک/ك و ارقام فارسی و شماره تلفن با هر شکلی مشکلی ایجاد نمی‌کنند) و فیلتر وضعیت
- ثبت و ویرایش، تشخیص بیمار تکراری، حذف قابل برگشت
- بستری: بیمارستان، بخش، تخت، اتند، **مدت بستری بر اساس روز و ساعت** (اگر ساعت بستری را ندانید، ۱۲:۰۱ ظهر فرض می‌شود و فقط روز نشان داده می‌شود)، ترخیص
- همراهان با تماس و کپی شماره
- نوت‌ها: شرح حال، پراگرس (SOAP)، کانسالت، رویداد مهم، ترخیص و… با وویس، سنجاق و پیش‌نویس — **آنچه می‌نویسید خودکار نگه داشته می‌شود**؛ اگر اپ بسته شود یا باتری تمام کند، متن برمی‌گردد
- کاردکس: دارو، سرم، رژیم، دستور پرستاری — با **شمارنده‌ی روز درمان (D5)** و توقف/قطع با یک لمس
- آزمایش: پنل‌های آماده (CBC، بیوشیمی، LFT، ABG، …)، چسباندن از اکسل، عکس برگه و وارد کردن مقادیر از روی عکس، **جدول روند** و نمودار
- تصویربرداری: گزارش، و مهم‌تر: **کجاست و روی چه سیستمی می‌شود دیدش**
- گالری عکس (ضایعه، ظاهر، رادیولوژی، مدارک) با کراپ و بزرگ‌نمایی، و وویس‌نوت — برای عکس بالینی و رادیولوژی، **اصل عکس** هم نگه داشته می‌شود
- پیگیری‌ها با یادآور گوشی، و صفحه‌ی «امروز» برای کارهای موعددار

**پزشکان**
- دفترچه‌ی اساتید، همکاران و پزشکان ارجاع؛ جستجو با نام یا تخصص، و **فیلتر تخصص** از فهرست آماده (تخصص و فوق‌تخصص)
- تماس، پیامک، واتس‌اپ، تلگرام و کپی شماره با یک لمس؛ آدرس و ساعات مطب، تعرفه و بیمه‌ها
- **امتیاز شخصی** ۶ معیاره با دلیل — هر بار که نظرتان عوض شد امتیاز تازه ثبت می‌شود و قبلی‌ها هم می‌مانند
- پروفایل شخصی: زادگاه، دانشگاه، علایق، نحوه‌ی آشنایی، سبک ارتباط
- **مناسبت‌ها و تولد شمسی** با یادآور چند روز قبل، متن آماده‌ی تبریک، و باز شدن پیام‌رسان خودتان با متن پر‌شده

**دانش**
- **مباحث**: خلاصه‌ی هر موضوع با نام استادی که تدریسش کرده — جستجو با نام استاد هم کار می‌کند — به‌علاوه «عین حرف استاد»، نکته‌های کلیدی، منبع، وویس‌نوت و علامت «نیاز به مرور» برای امتحان
- **رشته‌ها**: برای هر رشته ماهیت کار، طول رزیدنتی، سبک زندگی، بازار کار، مزایا و معایب، و اینکه چه کسی این‌ها را گفته
- **نسخه‌های روتین**: قالب نسخه‌های خودتان با توصیه، هشدار و پیگیری؛ کپی متن با یک لمس و شمارش دفعات استفاده (پرکاربردها خودشان می‌آیند بالا)
- **دفترچه‌ی ایده**: هر چه سر شیفت به ذهن رسید، با وضعیت و اولویت

**مرجع و امنیت**
- شماره‌های داخلی همه‌ی بیمارستان‌ها، قابل جستجو، با تماس مستقیم از بیرون
- مکان‌ها با مسیریابی در نشان/بلد/گوگل
- بکاپ رمزنگاری‌شده‌ی خودکار و بازگردانی کامل
- قفل اپ با اثر انگشت
- **گاوصندوق رمزها**: یوزرنیم و پسورد سامانه‌ها؛ پسورد با رمز جداگانه‌ی گاوصندوق رمزنگاری می‌شود و حتی داخل بکاپ هم رمزگذاری‌شده می‌ماند

**همه‌ی ماژول‌های نقشه‌ی راه ساخته شده‌اند.** از این به بعد: تست روی گوشی، پرداخت به جزئیات، و هر چه خودتان در «دفترچه‌ی ایده» بنویسید.
